# 现在是本项目唯一用的环境（comp0190-msn），覆盖：notebooks/explore_skull.ipynb、
# src/data/prepare_skullfix.py，以及 notebooks/demo/ 里那两个 MSN
# (PCT + BERT 多模态点云自编码器) demo notebook。
# 曾经跟一个额外的 comp0190（torch）环境分开装，是为了跟 torch 彻底隔离——
# 同一个环境里同时装 tensorflow[and-cuda] 和 torch，两边的 nvidia-nccl
# 包（cu12 / cu13）会装到同一个物理路径互相覆盖，导致 torch 崩掉。当前代码库
# 完全没有用到 torch，那个环境已删除；以后真要接回 torch 记得重新拆分。
#
# 版本限制的原因：
#   - Python 必须是 3.11：PyPI 上 tensorflow<2.16 没有 cp312 wheel。
#   - tensorflow 必须 <2.16：这是 transformers 官方验证过的、还带 TFBertModel
#     的最后一档 TF 版本；更高版本的 TF 默认 Keras 3，需要 numpy>=2，
#     跟这里 numpy<2 的要求冲突。
#   - transformers 必须 <5：5.0 开始彻底砍掉了 TensorFlow 后端（TFBertModel 等）。
#   - [and-cuda] extra 让 tensorflow 自带匹配的 CUDA 12 库，否则找不到 GPU。
#   - hf_transfer：这台机器全局开了 HF_HUB_ENABLE_HF_TRANSFER=1（加速 HuggingFace
#     下载），不装这个包的话 TFBertModel.from_pretrained 会直接报错退出。
